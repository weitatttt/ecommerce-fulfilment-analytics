# Dataset source and access

The source CSV supplied with this project has 180,519 order-item records and 53 columns, including customer-related fields. The original academic report and available file metadata do not identify a verifiable original publisher, download URL, licence, or permission to redistribute. Its filename `data.csv` is not a sufficient source citation. Accordingly, no dataset or row-level export is included here, and this repository does not grant reuse rights.

To reproduce the app, obtain a copy through an authorised source under terms that permit your intended use, name it `data.csv`, and place it beside `app.R` locally. Check its provenance and licence independently before using or sharing it. Do not commit customer names, addresses, coordinates, identifiers, or password-related fields. See [requirements.md](requirements.md) for the columns the application needs.

The assignment PDF is also excluded: it contains academic context and embedded screenshots. Five cropped dashboard panels are included solely to illustrate this case study; they retain the existing chart results.
